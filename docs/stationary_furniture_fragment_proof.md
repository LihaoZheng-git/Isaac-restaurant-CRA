# Bounded stationary fragment proof

Separate default-OFF `--stationary-furniture-fragment-proof` requires the existing
stationary-furniture-memory experiment. It addresses the preserved v2d failure:
an already-qualified four-point fragment remained observed, but its larger
parent's centroid velocity and a few unsupported remote points excluded it.

For an absent, already-qualified original fragment, the option requires every
original point to have repeated current world support: at least three distinct
actual scans spanning .2s, correspondence within .06m, source gaps at most .35s.
The current covering points also need that repeated support, at least three
distinct returns and one uniquely covering owner. Competing moving geometry,
ambiguous ownership, significant unclustered support and all existing human
mask/body/uncertainty exclusions reject. Unpublished candidates are ineligible.

Only the original piece can keep its original bounded geometry prior and a
current whole-surface coverage proof. The suspect parent stays excluded from
stationary enrollment, and its unverified parts are never retained. Its actual
raw occupancy and measured/inferred velocity still enter the normal pipeline.
A dedicated history contains only positively supported local fragment returns;
it cannot qualify a new surface or renew a factor. Shared source timestamps are
counted once. A source gap clears the repeated-support proof.

Original geometry, track/source/frame, qualification, risk, uncertainty radius
and ten-second retention expiry remain. After expiry only the existing continuous
fresh observed-surface association may continue; failed continuity cannot revive
an expired query. The continuity guard still checks actual current-field whole
geometry, clipping, risk and flux before granting an exception. Memory remains
transactional with field admission. Independent human truth audits the retained
and observed proof surfaces; it never supplies runtime evidence.

The recipe `configs/restaurant_service_demo_v2_fragment_proof.json` differs from
v2 only by this explicit option on the three furniture-memory commands. All
scene, nominal, CRA, fixed lambda, margins, source clocks, motion limits and
arrival/stopping checks stay unchanged. Fresh actor, component, startup and
near-human stationary gates are required before the full route. Unit success
and the saved adjacent-scan diagnosis are not native navigation acceptance.

Validation before native execution:3424 unit tests passed in119.11s; Ruff and
diff checks passed. Focused tests cover legacy rejection versus the opt-in,
partial/moving fragments, person exclusions, source gaps, ambiguous owners,
unclustered/competing moving returns, duplicate scan clocks, no parent enrollment,
unchanged expiry, normal/fast parent transitions, current-field risk/flux/clipping
and independent human audits. Both real CLI parsers reject the option without
memory; recipe parity verifies no other experiment setting changed.
