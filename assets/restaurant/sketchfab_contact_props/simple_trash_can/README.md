# Simple Trash Can

Original user-downloaded model by Andrew.Mischenko, licensed CC BY 4.0:
https://sketchfab.com/3d-models/simple-trash-can-beb82ad22e354b1e900b7756b55c9ac0

The supplied `source/license.txt` contains the full attribution. Preserve these
credits with derived images/video. `manifest.json` fingerprints the original ZIP
and its unmodified glTF, buffer and license. The installed Isaac converter creates
`converted.usdc`; it does not change the original files.

The separate stationary bench retains the complete 668-triangle mesh, including
its original lid/opening and material. A uniform scale sets an authored height of
0.50 m (about 0.296 m diameter), grounded at the existing prop-test position.
No smoothing, geometry repair, material replacement or contact label is applied.
This is a candidate rounded comparison, not an assumed low-risk measurement.
Authored dimensions and identity are evaluation metadata only; mass, contact
and CRA must come from the existing sensor pipeline and labeled priors.
